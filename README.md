# Atlas AutoShorts — Windows releases

This public repository distributes the Windows installer for Atlas AutoShorts. The application's source code, API keys, and customer videos are not stored here.

Installers are published under [Releases](https://github.com/xderrickp81-gif/atlas-autoshorts-releases/releases), and the app's **Check for Updates** control looks for newer versions there.

The installer is currently not code-signed. Windows SmartScreen may show an unfamiliar-publisher warning. Keep Windows Defender enabled and verify a release before installation.

Owner: xderrickp81-gif. Initial version: 1.2.0.
